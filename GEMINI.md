# Block Puzzle 10x10 - Project Context

## Project Overview
This project is a high-quality, fully offline, single-player block puzzle game for iOS and Android.

## Technology Stack
*   **Runtime:** React Native with Expo.
*   **Language:** TypeScript.
*   **State Management:** Zustand.
*   **Styling:** NativeWind.
*   **Persistence:** MMKV.
*   **Testing:** Jest.
*   **Package Manager:** `bun`.

## Key Commands
*   **Install:** `bun install`
*   **Start:** `bun start`
*   **Test:** `bun x jest`
*   **Lint:** `bun run lint`
